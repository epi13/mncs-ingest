# Examples

Examples in this directory should demonstrate semantic convergence rather than merely syntax.

A good example set contains several different source representations of the same bounded observation and the canonical semantic fragment they are expected to produce.

Initial example family:

```text
Alexander gave Finn 3 apples.
Finn received three apples from Alexander.
```

plus equivalent structured-event and native-MNCS inputs.

Examples should eventually be executable test fixtures. Until then, avoid adding large illustrative corpora that are not tied to a concrete conformance or research question.
